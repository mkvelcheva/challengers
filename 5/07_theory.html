В горния код идеята е следната - във всеки момент знаем (чрез променливата brOtpechataniZvezdi) колко звезди сме отпечатили до момента. Десет пъти повтаряме следното: ако не сме отпечатили всички нужни звезди (тоест brOtpechataniZvezdi < brZvezdiZaOtpechatvane), отпечатваме една и увеличаваме броя на отпечатаните с едно.

Лесно се забелязва, че програмата ще изпълни точно толкова от if-овете, колкото е въведената стойност (която по условие е не по-голяма от 10). Как обаче да решим задачата, при по-големи ограничения - например X <= 1000? Очевидно не е добре да пишем хиляди if-ове.

Това, което ще използваме за да решим задачата по по-хитър и лесен начин са тъй наречените цикли. Най-простият от тях е цикълът while. В общия случай той изглежда по следния начин - много подобно на if: 

while(<условие>) {
    <код за изпълнение, ако условието е вярно>
}

Разликата с if е че след като тялото на while-а се изпълни, не се продължава на реда след него, ами програмта се връща обратно до самия while и проверява пак условието. Ако то все още е вярно, пак се изпълнява тялото и т.н. докато (това значи while на английски) евентуално условието не стане грешно.

Използвайки while можем да решим задачата по следния начин: 

#include<iostream>
using namespace std;
int main()
{
    int brZvezdiZaOtpechatvane;
    cin >> brZvezdiZaOtpechatvane;

    int brOtpechataniZvezdi = 0;
    while(brOtpechataniZvezdi < brZvezdiZaOtpechatvane)
    {
        cout << "*";
        brOtpechataniZvezdi = brOtpechataniZvezdi + 1;
    }

    return 0;
}

Логиката на решението е абсолютно аналогична на тази на предишното, но този път няма нужда да копираме един и същи if много пъти и програмата работи за произволно големи стойности.

Винаги когато искаме да направим нещо много на брой пъти ще го правим така (или с някой от другите цикли, за които ще учим по-нататък). Ще имаме броячна променлива (например tekushtaStupka), започваща от 0, която на всяко изпълнение (стъпка) на while-а ще увеличаваме. Самият цикъл ще се изпълнява докато не стигнем искания брой изпълнения (например obshtoStupki) - тоест условието на while-а ще е tekushtaStupka < obshtoStupki.

2. Безкрайни цикли

Как изобщо обаче условието на while би се нарушило в някакъв момент от време? Със сигурност трябва нещо да се промени в самото тяло на цикъла (например стойността на някоя променлива), в противен случай няма как условието да бъде нарушено. Ако условието никога не се наруши, програмата продължава да изпълнява тялото на цикъла до безкрай. Много често програмистите правят тази грешка - да забравят например да увеличават брояча на цикъла - и пишат безкрайни цикли.

Например ако в примерната задача отгоре изпуснем да увеличаваме брояча на цикъла, то ще получим безкраен цикъл, който никога няма да спре да изпечатва звезди на екрана: 

...
int brOtpechataniZvezdi = 0;
while(brOtpechataniZvezdi < brZvezdiZaOtpechatvane)
{
    cout << "*";
}
...

Много често при стигане до безкраен цикъл програмата изглежда "забила" - сякаш чака да се въведе нещо, но не позволява.

Ако на състезание без да искаме направим безкраен цикъл, системата ще ни покаже като резултат TL (Time limit), тоест че програмата ни е отнела твърде много време, и няма да ни даде точки на съответния тест.

#include<iostream>
using namespace std;
int main()
{
    int x, y;
    int tekushtaStoinost;
    cin >> x >> y;

    if(x < y)
    {
        tekushtaStoinost = x;
        while(tekushtaStoinost <= y)
        {
            cout << tekushtaStoinost << " ";
            tekushtaStoinost = tekushtaStoinost + 1;
        }

    else
    {
        tekushtaStoinost = x;
        while(tekushtaStoinost >= y)
        {
            cout << tekushtaStoinost << " ";
            tekushtaStoinost = tekushtaStoinost - 1;
        }
    }

    return 0;
}

Задача 5

За всяко от числата от x до y, изведи '.', ако се дели на 2, 'х' ако се дели на 3 или '-' ако се дели и на двете (нищо в противен случай). (x <= y <= 10000)

вход:
7 17
изход:
.x.-.x.

пояснение: 7-нищо, 8-точка, 9-точка, 10-точка, 11-нищо и т.н.

Покажи решение 
#include<iostream>
using namespace std;
int main()
{
    int ot, doo;
    cin >> ot >> doo;

    int tekushto = ot;
    while(tekushto <= doo)
    {
        if(tekushto % 2 == 0 && tekushto % 3 != 0)
        {
            cout << ".";
        }
        if(tekushto % 2 != 0 && tekushto % 3 == 0)
        {
            cout << "x";
        }
        if(tekushto % 2 == 0 && tekushto % 3 == 0)
        {
            cout << "-";
        }

        tekushto = tekushto + 1;
    }

    cout << "\n";
    return 0;
}
