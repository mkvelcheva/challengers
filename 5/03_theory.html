1. Условният оператор if

С if изпълняваме команда само когато е изпълнено дадено условие.

В условието например можем да сравняваме стойности. Използваме == за проверка за равенство (А НЕ =), < и > за „по-малко“ и „по-голямо“, <= и >= за „по-малко или равно“ и „по-голямо или равно“.
Много внимаваме да не изпозлваме = (единично) в условието! 

if (<условие>) {
    <код за изпълнение, ако условието е вярно>
} 

if (5 < 10) {
    cout << "pet e po-malko ot deset" << "\n";
    cout << "oshte neshto";
}

Задача 1

В тенджерата има X кюфтета и Y кебапчета. Трябва да си ги разделите поравно с другарчето до вас: всеки да получи равен брой кюфтета и равен брой кебапчета. Не можем да режем храната (нямаме нож). Изведете da, ако е възможно и ne в противен случай. Вход: 23 13 Изход: ne Вход: 20 18 Изход: da
Покажи решение 
#include <iostream>
using namespace std;

int main() {
    int x, y;
    cin >> x >> y;
    if (x % 2 == 0) {
        if(y % 2 == 0) {
            cout << "da";
        }
        if(y % 2 == 1) {
            cout << "ne";
        }
    }
    if (x % 2 == 1) {
        cout << "ne";
    }
    return 0;
}

С == проверяваме дали две стойности са равни. Понякога е удобно обратното - да проверим дали две неща са различни.
Това става с !=.

2. Няколко условия едновременно

В горните задачи би било много удобно да можем с един if да проверяваме няколко неща наведнъж. Например, дали две условия са изпълнени едновременно или поне едно от тях е изпълнено.

В C++ съществуват логическите оператори "и" и "или", с които можем да комбинираме прости проверки в по-сложни.

"и" се пише с && (Shift + 7)
"или" се пише с || (Shift + \) 

if (<условие_1> && <условие_2>) {
    cout << "i dvete sa verni";
}
if (<условие_1> || <условие_2>) {
    cout << "pone ednoto e vqrno (a moje i dvete)";   
}

По този начин можем да решим задачи 1.2 и 1.3 по-лесно.

Покажи решение 1.2 
#include <iostream>
using namespace std;

int main() {
    int x, y;
    cin >> x >> y;
    if(x % 3 == 0 && y % 3 == 0) {
         cout << "da";
    }
    if(x % 3 != 0 || y % 3 != 0) {
        cout << "ne";
    } 
    return 0;
}
Покажи решение 1.3 
#include <iostream>
using namespace std;

int main() {
    int x, y;
    cin >> x >> y;
    if(x % 3 == 0 || y % 3 == 0) {
         cout << "da";
    }
    if(x % 3 != 0 && y % 3 != 0) {
        cout << "ne";
    } 
    return 0;
}

Задача 2

Задача 2.3

Ако съм на диета, трябва да изям само половината от Y кюфтета, които иначе искам да изям :( . Въвеждат се Y, X, Z и t в този ред. Ако t = 0 не съм на диета, а ако t = 1 съм на диета. Ако съм на диета изведете " Da, shte se naqdesh i shte si ostanesh debel, dori da si na dieta" или "Ne, shte si ostanash gladen, zashtoto si na dieta". Обещавам, че Y е четно число. Вход: 42 10 10 0 Изход: Ne, shte si ostanash gladen Вход: 42 10 10 1 Изход: Da, shte se naqdesh i shte si ostanesh debel, dori da si na dieta
Покажи решение 
#include <iostream>
using namespace std;

int main() {
    int kuftetaIma, gladnost, kebabchetaIma, naDietaLiSum;
    cin >> gladnost >> kuftetaIma >> kebabchetaIma >> naDietaLiSum;
    if(naDietaLiSum == 0) {
        if(kuftetaIma + kebabchetaIma * 2 >= gladnost) {
            cout << "Da, shte se naqdesh i shte si ostanesh debel";
        }
        if(kuftetaIma + kebabchetaIma * 2 < gladnost) {
            cout << "Ne, shte si ostanash gladen";
        }
    }
    if(naDietaLiSum == 1) {
        if(kuftetaIma + kebabchetaIma * 2 >= gladnost / 2) {
            cout << "Da, shte se naqdesh i shte si ostanesh debel, dori da si na dieta";
        }
        if(kuftetaIma + kebabchetaIma * 2 < gladnost / 2) {
            cout << "Ne, shte si ostanash gladen, zashtoto si na dieta";
        }
    }
    return 0;
}

4. Палиндроми

Палиндром е число, което се чете еднакво отляво надясно и отдясно наляво.

Примери: 121, 22, 12321, 4

Задача 3

Въвежда се едно двуцифрено число. Проверете дали е палиндром. Вход: 22 Изход: palindrom Вход: 16 Изход: NEpalindrom
Покажи решение 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if(n / 10 == n % 10) {
        cout << "palindrom";
    } 
    if(n / 10 != n % 10) {
        cout << "NEpalindrom";
    }
    return 0;
}
