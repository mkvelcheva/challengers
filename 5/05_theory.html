1. Else

Досега, когато искахме да проверим дали дадено условие е изпълнено, използвахме if.

Например, нека имаме три числа x, y и z. Искаме да проверим дали и трите числа се делят на 3. Можем да запишем:

if (x % 3 == 0 && y % 3 == 0 && z % 3 == 0) {
    cout << "da";
}
if (x % 3 != 0 || y % 3 != 0 || z % 3 != 0) {
    cout << "ne";
}

Тук правим две отделни проверки:

  • първата проверява дали и трите числа се делят на 3
  • втората проверява дали поне едно от числата не се дели на 3

Доста често се налага да пишем подобен код - да прави едно нещо понякога и друго нещо в другите случаи (иначе). В C++ за удобство има командата else, която ни позволява да не пишем обратното условие на ръка всеки път.

if (x % 3 == 0 && y % 3 == 0 && z % 3 == 0) {
    cout << "da";
}
else {
    cout << "ne";
}

else означава "в противен случай".

Тоест програмата по-горе работи така:

  • Ако и трите числа се делят на 3 -> извеждаме "da".
  • В противен случай -> извеждаме "ne".

Така кодът става по-кратък, по-ясен и не правим излишна проверка.

Общ вид 
if (<условие>) {
    cout << "izpulnqva se, ako uslovieto e vqrno";
}
else {
    cout << "izpulnqva se, ako uslovieto e greshno";
}

Ясно е, че за да ползваме else трябва преди него да има if. Също така за всеки if може да има най-много един else.

Можем например да решим задача 2.3 от седмица 3 по следния начин, използвайки else за удобство.

Покажи решение 
#include <iostream>
using namespace std;

int main() {
    int kuftetaIma, gladnost, kebabchetaIma, naDietaLiSum;
    cin >> gladnost >> kuftetaIma >> kebabchetaIma >> naDietaLiSum;
    if(naDietaLiSum == 0) {
        if(kuftetaIma + kebabchetaIma * 2 >= gladnost) {
            cout << "Da, shte se naqdesh i shte si ostanesh debel";
        }
        else {
            cout << "Ne, shte si ostanash gladen";
        }
    }
    else {
        if(kuftetaIma + kebabchetaIma * 2 >= gladnost / 2) {
            cout << "Da, shte se naqdesh i shte si ostanesh debel, dori da si na dieta";
        }
        else {
            cout << "Ne, shte si ostanash gladen, zashtoto si na dieta";
        }
    }
    return 0;
}
