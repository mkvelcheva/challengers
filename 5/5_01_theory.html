2. Първата команда: cout

cout отпечатва текст на екрана. Напиши и стартирай цялата програма:

#include <iostream>
using namespace std;

int main() {
    cout << "Az obicham kufteta!";
    return 0;
}

Резултат: Az obicham kufteta!

Задача 1

Напиши нещо интересно за себе си. Например: „Az se kazvam Doni i mnogo obicham da qm parjoli. Kufteta sashto!“
Покажи решение
#include <iostream>
using namespace std;

int main() {
    cout << "Az se kazvam Doni i mnogo obicham da qm parjoli. Kufteta sashto!";

Това е пример. Напиши свое изречение.

3. Нов ред: \n

С \n отпечатваме следващия текст на нов ред.

#include <iostream>

4*. Нарисувай един от лекторите със звездички

Използвай cout, звездички (*) и интервали. Измисли собствен портрет. Може да е усмихнат, с очила или с необичайна прическа! Предизвикателство: направи портрета с поне 5 реда. Не е необходимо да прилича съвсем на лектора — бъди креативен!
Покажи решение
#include <iostream>
using namespace std;

int main() {
    cout << "  *****\n";
    cout << " * * * *\n";
    cout << " *  *  *\n";
    cout << " * *** *\n";
    cout << "  *****\n";
    return 0;
}

Това е само един възможен портрет.

5. Променливи: int

Досега програмите винаги отпечатват едно и също. С променливите можем да съхраняваме и променяме числа. int означава цяло число.

Кюфте = променлива!

#include <iostream>
using namespace std;

int main() {
    int kufteta = 16;
    cout << kufteta << "\n";
    kufteta = kufteta - 5;
    cout << kufteta << "\n";
    return 0;
}

Резултат:

16 11

Операторът = записва пресметнатата стойност отдясно в променливата отляво.

6. Вход от клавиатурата: cin

cin прочита стойност, въведена от клавиатурата.

#include <iostream>
using namespace std;

int main() {
    int x;
    cin >> x;
    cout << x + 2 << "\n";
    return 0;
}

Примерен вход: 10   Изход: 12

Задача

Въведи число и изведи числото, което е с 2 по-голямо от него, и числото, което е с 5 по-голямо, разделени с интервал. Примерен вход: 10 Изход: 12 15
Покажи решение
#include <iostream>
using namespace std;

int main() {
    int x;
    cin >> x;
    cout << x + 2 << " " << x + 5 << "\n";
    return 0;
}

7. Сметки: +, -, *, /

Можем да събираме, изваждаме, умножаваме и делим цели числа.

#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << "\n";
    cout << a - b << "\n";
    cout << a * b << "\n";
    cout << a / b << "\n";
    return 0;
}

Примерен вход: 14 3   Изход: 17, 11, 42, 4 (на отделни редове)

8. Деление на цели числа

При деление на две числа от тип int дробната част се премахва. Например 7 / 2 е 3. За неотрицателни числа закръглянето нагоре при деление на 2 може да се получи с (x + 1) / 2.

#include <iostream>
using namespace std;

int main() {
    int x;
    cin >> x;
    cout << x / 2 << "\n";
    cout << (x + 1) / 2 << "\n";
    return 0;
}

Примерен вход: 7   Изход: 3 и 4 (на отделни редове)

9. Температури

Формули: F = C × 9 / 5 + 32 и C = (F − 32) × 5 / 9. Тук резултатът е цяло число.

От Целзий към Фаренхайт

#include <iostream>
using namespace std;

int main() {
    int c;
    cin >> c;
    cout << c * 9 / 5 + 32 << "\n";
    return 0;
}

Примерен вход: 20   Изход: 68

От Фаренхайт към Целзий

#include <iostream>
using namespace std;

int main() {
    int f;
    cin >> f;
    cout << (f - 32) * 5 / 9 << "\n";
    return 0;
}

Примерен вход: 68   Изход: 20

10. Купон с кюфтета

Има n маси. На първата има 1 кюфте, на втората 2, …, на последната n. Общият брой се намира с формулата n × (n + 1) / 2.

#include <iostream>
using namespace std;

int main() {
    int broiMasi;
    cin >> broiMasi;
    cout << broiMasi * (broiMasi + 1) / 2 << "\n";
    return 0;
}

Примерен вход: 7   Изход: 28
