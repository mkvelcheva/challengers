1. Когато числата станат големи

В една програма можем да пазим цели числа в променливи. Типът int е удобен за по-малки стойности. Когато резултатът може да е много голям, използваме long long.

Представете си редица от маси: на първата има 1 кюфте, на втората - 2, на третата - 3 и така нататък. Как се променя общият брой кюфтета, когато масите станат много?

long long може да пази много по-големи цели числа от обичайния int. Например един милион маси са достатъчни, за да помислим внимателно кой тип да изберем.

Задача 1. КУПОН!

поредица от маси! Въвеждат ни колко са масите на маса 1 има 1 кюфте, на маса 2 - 2 кюфтета, на broiMasi-тата има broiMasi кюфтета. Програмата да извежда колко кюфтета има общо на всички маси. пример: вход: 7 изход: 28 вход: 9 изход: 45
Покажи решение 
#include <iostream>
using namespace std;

int main() {
    long long broiMasi;
    cin >> broiMasi;
    long long obshto = broiMasi * (broiMasi + 1) / 2;
    cout << obshto;

    return 0;
}

2. Символи: char

char пази един символ: буква, цифра или знак. Например 'A', '7' и '#' са символи. Ограждаме ги с единични кавички, когато искаме да ги използваме в кода.

Всеки от символите има свой уникален числов код. Затова можем да сравняваме букви по техните кодове и с хитри сметки да получаваме други символи. Главните и малките латински букви имат постоянна разлика между кодовете си, което е удобно когато например искаме да напрвим някоя буква от малка в голяма или обратно. Кодовете на символите се определят от тъй наречената ASCII таблица.

Задача 2

Въвежда се символ, изпечатайте хоризонтална линия от 5 такива символа пример: # изход: #####
Покажи решение 
#include <iostream>
using namespace std;

int main() {
    char znak;
    cin >> znak;
    cout << znak << znak << znak << znak << znak;

    return 0;
}

Задача 2.1

Въвежда се символ, нарисувайте тригълник с 5 реда, съставен от въведения символ: пример: @ изход: @ @@ @@@ @@@@ @@@@@
Покажи решение 
#include <iostream>
using namespace std;

int main() {
    char znak;
    cin >> znak;
    cout << znak << '\n';
    cout << znak << znak << '\n';
    cout << znak << znak << znak << '\n';
    cout << znak << znak << znak << znak << '\n';
    cout << znak << znak << znak << znak << znak << '\n';

    return 0;
}

Задача 3

Въвежда се главна буква, изведете нейната съответна малка: пример: вход: A изход: a
Покажи решение 
#include <iostream>
using namespace std;

int main() {
    char bukva;
    cin >> bukva;
    int razlika = 'a' - 'A';
    char malka = char(bukva + razlika);
    cout << malka;

    return 0;
}

3. Число и символ, който изглежда като цифра

Числото 7 и символът '7' изглеждат сходно при извеждане, но се пазят по различен начин - например кодът на символът '7' е 55 (от ASCII таблицата). С число можем да смятаме; символът може да е част от текст или код.

Символите от '0' до '9' са подредени един след друг - тоест имат последователни кодове. Кодът на '0' е отправната точка, когато превръщаме едноцифрено число в символ. Подобно е и при буквите - ако към кодът на дадена буква добавим/извадим 1 получаваме кода на следващата/предишната в азбуката. Ако добавим/извадим 2 получаваме кода на по-следващата/по-предишната и т.н.

Задача 4

Въвежда се едноцифрено цяло число от 0 до 9. Превърнете го в съответния символ от тип char и го изведете.
Покажи решение 
#include <iostream>
using namespace std;

int main() {
    int cifra;
    cin >> cifra;
    char simvol = char(cifra + '0');
    cout << simvol;

    return 0;
}

4. Няма нужда да помним кодовете наизуст

Ако някога се чудим какъв код има даден символ или обратно - дадено число на кой символ е код - можем да използваме следните редове код.

cout << (char) 43 << '\n';
cout << (int) '#' << '\n';

Горният код ще изведе символа с код 43 и кода на символа '#'.

5. Целочислено деление и остатък

Когато делим две цели числа, / дава цялата част от частното, а % дава остатъка.

17 / 5  →  3
17 % 5  →  2

При деление на 10 остатъкът е последната цифра на числото, а целочисленото деление на 10 премахва последната цифра. Така можем да работим с отделните цифри на число.

Задача 5

Въвежда се число с поне 3 цифри. Изведете на отделени редове последната му цифра и числото с изтрита последна цифра. пример: вход: 1327 изход: 7 132
Покажи решение 
#include <iostream>
using namespace std;

int main() {
    int chislo;
    cin >> chislo;
    cout << chislo % 10 << '\n';
    cout << chislo / 10 << '\n';

    return 0;
}
