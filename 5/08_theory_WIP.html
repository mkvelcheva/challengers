1. Отделяне на цифри

В предишните теми имаше много задачи, в които се искаше да работим с цифрите на многоцифрени числа. За целта се научихме как да отделяме последната цифра на число - това беше остатъкът при деление на 10 на числото - и как да я "изтриваме" за да получим останалата част от числото - това беше числото разделено на 10 (и закръглено надолу).

До сега обаче винаги числата имаха някакъв фиксиран брой цифри - напрмер 3 или 4 - и за това кодът ни отделяше цифра точно толкова пъти. Как обаче да направим същото, ако не знаем колко цифри има числото? Ще го правим с while.

На всяка стъпка ще отделяме текущата последна цифра (% 10) на числото, ще правим каквото трябва с нея за задачата, след което ще я "трием" (/ 10) за следващата стъпка. Ще продължаваме така докато не "изтрием" всички цифри от числото - тоест докато то не стане равно на 0. 

int x, digit;
cin >> x;
while(x > 0) {
    digit = x % 10;
    <правим каквото трябва с цифрата>
    x = x / 10;
}

Покажи решение 
#include<iostream>
using namespace std;
int main()
{
    long long x;
    int digit;
    cin >> x;

    while(x > 0)
    {
        digit = x % 10;
        cout << digit << " ";
        x = x / 10;
    }

    return 0;
}

Задача 3

Въвежда се число X (0 < X < 1018). Изведете разликата между сборовете на цифрите на четните и нечетните позиции.

Позициите ще ги броим от 0 и от дясно наляво, тоест позицията на единиците ще е "позиция 0", десетиците ще са "позиция 1" и т.н. - по този начин сметките ни ще са по-удобни.

вход:
12345231
изход:
-3
Пояснение:
Цифрите на четните позиции са на единиците, стотитиците и т.н.: 1 + 2 + 4 + 2 = 9
Цифрите на нечетните позиции са на десетиците, хилядите и т.н.: 3 + 5 + 3 + 1 = 12

Подсказка

Направете променлива, която да следи коя поред е текущата позиция, до която сте стигнали. Чрез нея определяйте какво да правите със съответната цифра на числото.

Покажи решение 
#include<iostream>
using namespace std;
int main()
{
    long long x;
    int digit, position = 0;
    int sumOdd = 0, sumEven = 0;
    cin >> x;

    while(x > 0)
    {
        digit = x % 10;
        if(position % 2 == 0)
        {
            sumEven = sumEven + digit;
        }
        else
        {
            sumOdd = sumOdd + digit;
        }

        x = x / 10;
        position = position + 1;
    }

    cout << sumEven - sumOdd;
    return 0;
}

2. Степенуване

До сега няколко пъти говорихме за математическата операция "степенуване". Тя не е нищо сложно и представлява просто многократно умножение на нещо по себе си - подобно на умножението, което е многократно събиране на нещо със себе си.

В математиката пишем AB и четем "A на степен B". Например 23 (2 на степен 3), 57 (5 на степен 7) и 1018 (10 на степен 18). Стойността на AB е просто A умножено по себе си B пъти:
23 = 2 * 2 * 2 = 8
57 = 5 * 5 * 5 * 5 * 5 * 5 * 5 = 78125
1018 = 10 * ... * 10 (18 пъти) = 1000000000000000000

Специален случай е когато B е 0. Тогава приемаме, че резултатът е 1.
A0 = 1

Понеже в текстови файлове често не можем да пишем AB по технически причини, доста често ще пишем A^B имайки предвид А на степен B.

За щастие в C++ няма вградена операцията степенуване, така че ще ни се налага да я правим сами чрез цикли и умножения. Имайте предвид, че a^b в C++ значи нещо тотално различно (и ще говорим за него след доста време).

Задача 4

Въвеждат се числата A и B. Изведете 2A и 3B като посочете кое е по-голямото от двете, както е в примерите. A и B са неотрицателни и такива, че 2A, 3B < 1018.

вход:
11 7
изход:
2048 < 2187

вход:
12 7
изход:
4096 > 2187

Покажи решение 
#include<iostream>
using namespace std;
int main()
{
    int a, b;
    cin >> a >> b;

    long long twoPowA = 1;
    int step = 0;
    while(step < a)
    {
        twoPowA = twoPowA * 2;
        step = step + 1;
    }

    long long threePowB = 1;
    step = 0;
    while(step < b)
    {
        threePowB = threePowB * 3;
        step = step + 1;
    }

    cout << twoPowA << " ";

    if(twoPowA < threePowB)
    {
        cout << "<";
    }
    if(twoPowA > threePowB)
    {
        cout << ">";
    }
    if(twoPowA == threePowB)
    {
        cout << "=";
    }

    cout << " " << threePowB;
    return 0;
}
